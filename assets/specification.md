# DD-Mamba 方法规格与创新归纳（论文写作参考）

> 本文档归纳本仓库**实际实现并经 shipped 配置启用**的机制、各组件设计的独到之处，以及它们如何组合成一个整体，供撰写人工智能/神经网络论文时参考。所有数值与结论均可溯源到 `configs/`、`results/`、`assets/innovation.md`（创新核查报告）与 `assets/figures.md`（图表指南）中的实测材料；本文按证据强度区分"主结果承重"与"已实现待评估"，写作时请勿超出证据范围做声明。

---

## 1. 一段话总览

DD-Mamba 是一个双域（时域 + 频域）多变量时序预测模型：回看窗口经实例归一化后并行进入两条分支，每条分支内部携带一个线性锚（linear anchor），并输出一份**完整的预测**和一个通道特征；一个门控网络读取两个分支的特征，按通道对两份预测做凸组合；跨通道的交互则由变维双向 Mamba 在特征层统一承担。模型的核心主张可以概括为一句话：让时域与频域两条**各自完整、视角互补**的预测路径在预测层会合，由数据驱动的门控决定信谁，而不是把双域信息在中间特征层耦合起来。这一主张在全部 14 个 shipped 配置、论文报告的全部 11 个数据集上以同一结构成立（`fusion: gated` 无一例外）。

## 2. 核心创新（按证据强度排序）

### 2.1 预测级门控双域融合（主结果承重，全部 benchmark 使用）

**机制。** 每条分支输出完整预测 $y_{\mathrm{time}}, y_{\mathrm{freq}} \in \mathbb{R}^{B \times C \times H}$ 与通道特征 $f_{\mathrm{time}}, f_{\mathrm{freq}} \in \mathbb{R}^{B \times C \times D}$；门控网络以两支特征拼接为输入，输出每通道一个标量门：

$$g = \sigma\!\left(\mathrm{MLP}\!\left([f_{\mathrm{time}}; f_{\mathrm{freq}}]\right)\right) \in (0,1)^{B \times C}, \qquad \hat{y} = g \odot y_{\mathrm{time}} + (1 - g) \odot y_{\mathrm{freq}}$$

门是凸组合权重：输出被约束在两份分支预测所张成的线段上，两支互为"替代品"。结构上有一条硬约束——**不存在绕过两条分支直达输出的通路**，任何信息都必须以某支完整预测的形式参与融合。

**与已有工作的差异。** 双域类方法（DualNet、TF4TF、WaveFormer、TFKAN、FEDformer 等）普遍把频谱信息引入中间编码器、或在任一支形成预测**之前**的特征层做融合，双域对最终预测的贡献是隐式的；DD-Mamba 的两支各自形成完整预测后才做逐通道凸门融合，域特异性的贡献因此是显式可观测的（`return_components` 可分别导出两支预测与门控值，供 Fig.4/Fig.5 的机制分析）。

**初始化的讲究。** 门控偏置初始化为 2.2，即 $g_0 = \sigma(2.2) \approx 0.90$：模型从"时域主导"的起点出发。这不是任意选择——在未启用频域谱锚的数据集上频域预测头是随机初始化的，若从 0.5/0.5 起步，初始预测的一半是噪声，最高学习率阶段会被浪费在补偿噪声上。实测（ETTm1，全测试集 11425 窗口）训练后所有通道的门回落到 0.59–0.75、均值 0.654：门确实离开了时域主导的初值，按通道学到接近但非均匀的双域折中，且没有任何通道退化为单分支。

**配套的消融空间。** 融合组件还实现了 `sum`（等权平均）、`concat`（逐 horizon 步的门）、`residual`（单一标量）、`affine`（双独立门、无和一约束）、`doubly_residual`（N-BEATS 式残差加权）与 `time_only`/`freq_only`（单支消融）共八种模式，凸式与叠加式的设计权衡在代码文档中有明确论述——这为论文的融合消融实验提供了现成的、逐级放宽约束的假设序列。

### 2.2 线性锚 + 零初始化修正（主结果承重）

**机制。** 两条分支内部都是"线性锚 + 零初始化深度修正"的两段式。时域侧：序列分解（滑动平均提趋势）后，季节/趋势各经一个 $L \to H$ 线性映射相加得到 DLinear 式锚 $y_{\mathrm{lin}} = W_s \mathcal{S} + W_t \mathcal{T}$；深度路径（嵌入 → 因果 Mamba → 末态摘要 + 全窗嵌入）的特征经**零初始化**预测头给出修正量，$y_{\mathrm{time}} = y_{\mathrm{lin}} + \Delta y$，训练第 0 步 $\Delta y \equiv 0$。频域侧：可选 FITS 谱锚——一个零初始化的复数线性映射把长度 $L$ 窗的谱"上采样"为长度 $L+H$ 窗的谱，逆变换取末 $H$ 步作为线性外推预测（启用数据集：ETTh1、ETTh2、Weather；其余配置频域侧仅深度头）。

**设计独到处：初始化之间的协同。** 各个零初始化不是孤立技巧，而是一组互相配合的选择，这一点值得在论文中专门陈述：

- 门控偏置 2.2（$g_0 \approx 0.9$）与"时域锚精确、频域头可能随机"的现状匹配，起步即近似线性时域解；
- 叠加式融合模式的频域初始权重取 $0.1 > 0$ 而非 $0$：当谱锚与门权同时为零时，损失对二者的梯度互相为零，频域分支将永远得不到训练信号——一个正的小权重恰好规避这个双零不动点，且与凸式模式的初始频域份额（$1 - \sigma(2.2) \approx 0.1$）对齐；
- 结果是一个干净的性质：**初始模型近似为线性双域组合，深度部分只学修正**——在启用谱锚的数据集上精确成立（两支锚 + 零初始化头）；未启用谱锚时频域头随机初始化，但 $g_0 \approx 0.9$ 的时域主导起点使初始输出以线性时域解为主。两种情形下优化都从强基线附近出发、初期无系统性噪声注入，且每个深度模块的贡献可以被单独归因（关掉即退回对应线性解）。

### 2.3 跨分支权重共享的变维 Mixer（6 个高通道 benchmark 使用，精度中性验证）

**机制。** 变维双向 Mamba（把 $C$ 个通道当作长度为 $C$ 的序列做双向扫描）承自 S-Mamba；DD-Mamba 的增量是 `shared` 放置——只训练一份 mixer 权重、由两条分支共用（`both` 放置则是两支各一个独立 mixer）。ECL、Traffic、PEMS03/04/07/08 六个高通道 benchmark 的 shipped 配置使用 `shared`；Weather 与 Solar 用 `both`；ETT×4/Exchange/Illness 的 mixer 层数为 0（通道独立）。

**证据。** 消融显示共享不损精度：traffic 上 ΔMSE 约 +0.0007（多种子置信区间含 0）、electricity 上 −0.0001（`results/Ablation_{traffic,electricity}_mixer.json`）。共享的动机是参数效率：mixer 是高通道数据上参数量最大的部件之一，共享一份约省一半 mixer 参数。合理性也直观——两支的 mixer 做的是同一件事（在通道之间传递信息），没有理由必须学两套。

### 2.4 已实现但未进入 benchmark 的机制（写作红线）

以下机制在代码中完整实现、各有单链消融支持，但**没有任何 benchmark 配置启用**，除非补多种子消融实验，不能列为论文贡献：

- **alpha-RevIN**：把实例归一化强度连续化为 $\alpha \in [0,1]$（$x_{\mathrm{norm}} = \alpha(x - \mu)/\sigma + (1-\alpha)x$），可全局或逐通道学习，用于消除"RevIN 开/关"这类测试集消融的选择偏差；shipped 配置中 α 恒为 1.0（即标准 RevIN）。
- **Dispersion head**：从多分辨率历史统计预测逐 horizon 的正尺度因子，替代固定的 $\mu/\sigma$ 反归一化；shipped 配置均为 `dispersion: none`。
- **频域 BiMamba 扫频 bin**：把频率 bin 当序列做双向选择性扫描的备选谱编码器；所有 benchmark 配置使用复数线性滤波器，且论文方法章亦未主张该机制。

另有一条**论文-实现一致性警示**：论文方法章声明时域分支对所有任务使用因果 Mamba 编码器，但 ECL/Traffic/PEMS 的实际配置是 `time_encoder: mlp`（沿 S-Mamba 的"时间维 MLP + 变量维 Mamba"配方，高通道数据上更稳）。撰写或修改文稿时必须修正这一口径，或将配方差异如实陈述为逐数据集的设计选择。

## 3. 组件设计的独到之处

### 3.1 时域深度修正路径

每步输入是分解后的 $[\mathcal{S}_t, \mathcal{T}_t]$ 二元组而非原始值——尺度分离被预先喂给状态空间，状态容量不必再花在区分趋势与振荡上。编码用因果 Mamba 沿时间轴扫描，核心递推为

$$h_t = \exp(\Delta_t A)\, h_{t-1} + \Delta_t B_t\, z_t, \qquad o_t = C_t\, h_t$$

其中 $(\Delta_t, B_t, C_t)$ 由当前输入即时生成（"选择性"：逐时刻决定记多少、忘多少），$A$ 对角为负保证记忆衰减稳定。因果性使末状态 $h_L$ 成为整个回看窗的充分摘要——取末态而非池化是结构使然，不是凑合。摘要再与一个全窗线性嵌入（series embedding）相加构成通道特征：前者编码有顺序的动态，后者提供无序的全局视图，互为补充；该特征一份两用，同时喂本支预测头与融合门。

### 3.2 频域谱编码器

窗口经 rFFT 变换到谱域后，由一个可学习的复数矩阵 $W = W_r + \mathrm{i} W_i \in \mathbb{C}^{F \times F}$（$F = L/2+1$，$L=96$ 时 $F=49$）做全谱线性变换，实数运算展开为 $Y_r = W_r X_r - W_i X_i$、$Y_i = W_r X_i + W_i X_r$。三点设计值得强调：其一，**全局感受野由构造保证**——滤波矩阵稠密，每个输出 bin 看得见所有输入 bin，而 rFFT 本身就把整窗周期结构浓缩成少数显著谱线；其二，**相位被完整保留**——实部/虚部成对进入所有计算，只看幅度会丢失"何时发生"的信息，而水平漂移与相位偏移正是纯频域方法的典型失败模式；其三，**实测表明滤波器学到的是跨频率重组**——训练后 $|W|$ 的非对角能量占比 97.9%（ETTh1 checkpoint 实测，Fig.3），即模型主要在做跨 bin 的幅相重分配而非逐 bin 门控，这直接支撑"可学习谱滤波优于简单频谱截断"的论述。

### 3.3 变维 Mixer

把通道维当作序列、用双向 Mamba 扫描，以 $O(C)$ 代价完成跨通道信息交换（变维注意力是 $O(C^2)$，在 traffic 862 通道、PEMS07 883 通道的规模上正是训得动与训不动的差别）。双向是必须的：通道顺序任意，单向扫描只能让每个位置看见"前面"的通道，是人为偏置。每层的融合式 $u \leftarrow \mathrm{Fwd}(u) + \mathrm{Bwd}(\mathrm{flip}(u)) - u$ 让前向/反向各贡献一次残差混合、相减保持单一残差流。该构件与频域 bin 扫描复用同一实现——"无方向轴 + 需要全局交互"的组合在两处出现，构成 "selective scan everywhere" 的统一设计语言。

### 3.4 门控融合组件

见 §2.1。组件层面额外可写的是它的**可观测性**：门 $g$、两支预测、门控统计均可从一次前向中导出，使"融合在学什么"成为可实证检验的问题而非黑箱——Fig.4（逐通道均值门与分布）、Fig.5（单窗口加权分解）正是建立在这一能力上。论文写作时，这种"机制可检验性"本身可以作为方法叙事的一部分。

## 4. 整体的有机结合

DD-Mamba 不是新组件的堆叠，几个贯穿性的设计原则把各部件拧成了一个整体：

**其一，"锚 + 修正"在三个尺度上一致复用。** 分支内（DLinear 线性锚 + 零初始化深度头）、频域（FITS 谱锚 + 深度头）、融合层（$g_0 \approx 0.9$ 的时域主导起点 + 可学习门），是同一哲学——**从线性解出发，让深度部分只学残差**——在三个层级上的实例化。初始模型因此整体退化为（近似或精确的）线性双域组合，每个深度模块的贡献都可被单独归因；§2.2 所述的初始化协同（偏置 2.2、频域初始权 0.1 规避双零梯度不动点）保证了这套初始化在训练动力学上自洽。

**其二，"先通道独立、再跨通道"的两阶段通道处理。** 编码阶段所有通道共享权重、各自独立处理（廉价、防过拟合、可并行），跨通道依赖集中交给一个小而高效的变维 mixer 在特征层补足。这个划分让"是否建模跨通道依赖"成为一个可调旋钮而非架构分叉：ETT 类小通道数据 mixer 置零即为通道独立模型，electricity/traffic/PEMS 打开 2 层共享 mixer，Weather/Solar 用独立 mixer——逐数据集的调律通过配置完成，主干结构不变。

**其三，特征一份两用，融合门不需要额外信息通路。** 两支的通道特征既喂各自的预测头，也直接作为门控网络的输入——"预测级融合"的门信号来源于分支自身的表征，无需为融合另设编码器。这使融合组件极轻（一个小 MLP），也让门控行为与分支质量天然耦合。

**其四，对称的归一化进出与正交的可选件。** RevIN 在前端实例归一化、在后端对称反归一化，分支始终在标准化空间工作；FITS 锚、mixer 层数与放置、Solar 关闭 RevIN 等选择都是不触碰主干的开关，组合起来形成 §2.3/§2.4 所述的逐数据集配置矩阵。高通道数据上的整体配方（时间维 MLP + 变量维共享 Mamba + 门控双域）与 ETT 上的配方（因果 Mamba 时域 + 复数滤波频域 + 通道独立）共用同一顶层结构，差别只在开关档位——论文中这应表述为"一个架构、两种部署配方"，而非两个模型。

**其五，证据链与架构同等完整。** 主张"两支互补、门控在学"不只是说辞：分支移除的 ΔMSE 消融（`results/Ablation_*.json`）、谱滤波的非对角能量分析（Fig.3）、门控从 0.90 回落至 0.59–0.75 的全测试集统计（Fig.4）、单窗口的加权分解可视化（Fig.5）互相印证。方法叙事与机制证据一一对应，是这套设计"有机"的最终含义。

## 5. 论文写作要点

**叙事线建议**（与 `assets/figures.md` 的图序一致）：互补视角的动机（Fig.1：时域看得清趋势/局部、频域看得清周期/全局，单视角各有系统性盲区）→ 双完整预测 + 预测级门控的架构（Fig.2）→ 三个机制证据（Fig.3 谱滤波学到跨 bin 重组；Fig.4 门控离开时域主导初值、按通道学到非均匀折中；Fig.5 单窗口上凸组合同时修好两类误差）→ 组件消融与共享 mixer 的参数效率（Fig.6 及 Ablation 结果）。"锚 + 零初始化修正"作为贯穿性设计在方法章单独成段，配合"初始模型近似线性双域组合"的性质陈述。

**可以声明的贡献**：预测级门控双域融合（全部 benchmark）；跨分支联合的线性锚 + 零初始化修正设计（全部 benchmark，含初始化协同的动力学分析）；跨分支权重共享变维 mixer（6 个高通道 benchmark，精度中性、参数约减半）。

**不可以声明的**：alpha-RevIN、dispersion head、频域 BiMamba（已实现无 benchmark 证据）；任何未经 `--seeds 3+` 复跑的单种子结论（单种子 ΔMSE < 约 0.005 视为噪声）；"所有数据集使用因果 Mamba 时域路径"（高通道数据集实为 MLP 配方，文稿需修正或如实分述）。

**口径与纪律**：主结果表中基线数值为文献转载（S-Mamba / iTransformer 报告值），效率表为同环境实测，引用时保持该口径；ETT 数据集使用固定月边界切分协议；结果文件带 provenance 模式（resolved config + commit + seeds），发表前以统一基线脚本多种子复跑"requires rerun"配置——an expected value is not a result。
